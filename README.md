# Бюджет двоих — версия для прямой загрузки на GitHub Pages

Это статическая версия приложения в одном `index.html`. Она не требует npm, Vite, сборки или вложенных папок.

## Как опубликовать
1. Распакуйте архив.
2. Откройте репозиторий GitHub и загрузите все файлы из архива непосредственно в корень репозитория.
3. В репозитории откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, затем Save.
6. Откройте опубликованный адрес GitHub Pages.

Приложение загружает React, Babel и Tailwind с CDN, поэтому при первом открытии нужен интернет. Данные операций хранятся в LocalStorage браузера на конкретном устройстве. Для совместного использования данных между двумя телефонами потребуется отдельная синхронизация/бэкенд.
